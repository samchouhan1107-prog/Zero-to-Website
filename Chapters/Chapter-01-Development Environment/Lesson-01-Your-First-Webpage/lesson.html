Your First Webpage

Write, save, and preview your very first HTML document inside your browser.

1. Introduction

Every website in the world begins with a single file: index.html. In this lesson, you will create a real HTML file, write basic tags, open it in your web browser, and see your code transform into a live webpage.

2. Learning Objectives

  • ✔ Create and save an index.html file.
  • ✔ Write the basic HTML5 document boilerplate structure.
  • ✔ Understand the purpose of <!DOCTYPE html>, <head>, and <body>.
  • ✔ Open your file in Google Chrome, Edge, or Firefox.

3. Theory & Explanation

When you double-click an .html file on your computer, your default web browser reads the file from top to bottom. It does not display the angle brackets < > on screen; instead, it uses them as instructions to format headings, paragraphs, and images.

Key Principle

Content you want visitors to see (headings, buttons, text, pictures) must always live inside the <body> tag.

4. Real-World Example

Think of an HTML file like writing a letter:

  • The Envelope (<head>): Contains the recipient name, postage stamp, and title (metadata).
  • The Letter Paper (<body>): Contains the actual message, words, and drawings you want the reader to experience.

5. Visual Explanation

📁 My-First-Website
└── 📄 index.html
      ├── <!DOCTYPE html>  (Informs browser: HTML5 standard)
      ├── <html>
      │     ├── <head>      (Page title & charset)
      │     └── <body>      (Visible website content)
      │           ├── <h1>Hello World</h1>
      │           └── <p>Welcome to my site.</p>
      └── </html>

10. Real World Application

🏗️ How This Applies to Real Projects

Every professional website starts with proper HTML structure. What you're learning here forms the foundation of:

  • Portfolio Websites: Your personal showcase to employers
  • Business Landing Pages: Company websites with clear information hierarchy
  • E-commerce Product Pages: Structured product information and descriptions
  • Blog & Content Sites: Article layouts with proper heading structure

Pro Tip: Search engines like Google use your HTML structure to understand your content. Proper semantic HTML improves your SEO rankings.

  • HTML provides the foundational structure of all web pages.
  • The index.html filename is the standard entrypoint for all web servers.
