Your First Webpage

Every website in the world begins with a single file: index.html. In this lesson, you will create a real HTML file, write basic tags, open it in your web browser, and see your code transform into a live webpage.

  • ✔ Write the basic HTML5 document structure
  • ✔ Understand <!DOCTYPE html>, <head>, and <body>
  • ✔ Open your file in Google Chrome, Edge, or Firefox

1. Welcome to Web Development!

Every website you visit, from Google to Facebook to your favorite blog, starts with a simple HTML file. Think of HTML as the skeleton of a webpage - it provides the basic structure and content that browsers display.

🌟 Key Insight

HTML stands for HyperText Markup Language. It's not a programming language, but a markup language that uses tags to describe content structure.

📝 Real-World Example

Think of building a house: HTML is like the blueprint and framing, CSS is like the paint and decorations, and JavaScript is like the electrical and plumbing systems.

2. HTML Document Structure

Every HTML file follows a basic structure. Let's break down the essential components:

Basic HTML Template

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>This is my first webpage.</p>
</body>
</html>

🔤 <!DOCTYPE html>

Tells the browser this is an HTML5 document

📋 <head>

Contains meta information and title (not visible on page)

🎯 <body>

Contains all visible content (headings, paragraphs, images)
