Grade & Access Gatekeeper

🎯 Challenge Tasks (Level: Age 15+ to Professional)

  • 1. Parse an integer score from the provided input element
  • 2. Check boundary conditions: 90+ ('Senior Honors'), 75-89 ('Proficient Coder'), <75 ('Practice Needed')
  • 3. Use strict comparison operators (===, >=, <=)
  • 4. Style the resulting badge container dynamically with appropriate border and background colors
