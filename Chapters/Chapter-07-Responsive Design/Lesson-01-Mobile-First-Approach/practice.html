Practice Challenge 07.01

Mobile-First Stacked Profile Card

Create a user profile card that is vertically stacked by default, transitioning to a side-by-side layout at 600px+ width.

🎯 Challenge Tasks (Level: Age 15+ to Professional)

  • 1. Write default mobile styles: flex-direction: column and 100% width
  • 2. Add an additive @media (min-width: 600px) query
  • 3. Switch flex-direction to row with 24px column gap on desktop
  • 4. Ensure buttons meet the 44px touch height minimum
