🎯 Learning Objectives

  • ✔ Initialize repositories with git init and inspect status with git status.
  • ✔ Stage and commit snapshots with git add . and git commit -m "...".
  • ✔ Create feature branches with git checkout -b feature-name.
  • ✔ Connect to GitHub remotes and push code using git push -u origin main.
