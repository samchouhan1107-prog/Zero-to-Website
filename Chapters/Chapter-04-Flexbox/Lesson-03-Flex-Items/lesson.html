Lesson 03 — Flex Items

Explore how flex items behave inside a flex container, including their sizing and ordering rules.

Lesson Overview

This lesson covers flex item properties such as order, flex-grow, flex-shrink, and flex-basis.

Introduction

Flex items are the child elements inside a flex container. They receive layout behavior from the container and can be arranged, resized, and reordered using Flexbox properties.

Learning Objectives

  • Understand what makes an element a flex item.
  • Learn how order changes visual position.
  • Use flex-grow, flex-shrink, and flex-basis.

Theory

Each flex item can grow or shrink to fit available space. The flex shorthand combines growth, shrinkage, and base size into one value that controls behavior in the container.

Real World Example

Use flex items for cards, buttons, and columns where each piece needs to scale or remain balanced inside the layout.

Visual Explanation

Think of flex items as boxes in a row. One can be set to grow and fill extra space while another holds its base width and shrinks only if needed.

Code Example

.flex-item-1 { order: 2; flex: 2 1 180px; }
.flex-item-2 { order: 1; flex: 1 1 140px; }
.flex-item-3 { order: 3; flex: 1 2 120px; }

Code Breakdown

Each item can have a separate order value. The first number in flex is grow, the second is shrink, and the third is basis.

Related Topics

This lesson builds on the flex container concepts and leads into alignment properties in Lesson 04 and Lesson 05.

Practice Challenge

Arrange three cards so the middle card grows larger than the others and appears first in order.

Mini Project

Create a simple feature row where one item expands and the others remain fixed in width on larger screens.

Summary

Flex items are the building blocks inside a flex container. Their order, growth, shrinkage, and base size determine how the final layout responds.
