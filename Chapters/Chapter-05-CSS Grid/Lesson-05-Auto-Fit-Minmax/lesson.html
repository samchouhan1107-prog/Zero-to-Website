Auto-fit, Minmax & Responsive Grids

Build inherently responsive bento grids that reflow flawlessly from 1 column on smartphones to 4 columns on widescreen monitors without a single media query!

Magic Formula

repeat(auto-fit, minmax(...))

auto-fit vs fill

Collapse vs preserve empty

Zero Queries

Intrinsic responsiveness

Estimated Time

30 Minutes

1. The Magic One-Liner Responsive Grid

.responsive-cards {
    display: grid;
    /* Automatically creates as many columns as will fit, with min 260px and max 1fr */
    grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
    gap: 20px;
}
