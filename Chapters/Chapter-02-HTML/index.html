Why HTML Exists

The internet needs a way to organize information. HTML was created to give webpages structure.

  • Headings organize information.
  • Paragraphs display content.
  • Images show visual information.
  • Links connect webpages together.
  • Forms collect user information.

Without HTML, browsers would not know how to display a webpage.

Learning Objectives

  • Understand what HTML is.
  • Learn how HTML documents are created.
  • Understand tags and elements.
  • Learn how browsers interpret HTML.
  • Create your first webpage structure.
