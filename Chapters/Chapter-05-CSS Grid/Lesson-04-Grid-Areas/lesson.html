Grid Template Areas

Visually sketch entire web layouts using named string ASCII representations like 'header header' and 'sidebar content'.

Syntax

grid-template-areas

Item Assignment

grid-area: name

Blank Cells

The dot (.) syntax

Estimated Time

30 Minutes

1. Declarative Layout Mapping

.page-layout {
    display: grid;
    grid-template-columns: 240px 1fr;
    grid-template-rows: 70px 1fr 60px;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    gap: 16px;
}

header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: main; }
footer { grid-area: footer; }
