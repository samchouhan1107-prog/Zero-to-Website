Practice Challenge 07.02

Adaptive 3-Tier Breakpoint Banner

Create a banner that transitions its layout and color palette across Phone (<640px), Tablet (640-1024px), and Desktop (>1024px).

🎯 Challenge Tasks (Level: Age 15+ to Professional)

  • 1. Define base styles for mobile: single column and orange accent
  • 2. Add @media (min-width: 640px) tablet breakpoint with blue styling
  • 3. Add @media (min-width: 1024px) desktop breakpoint with emerald styling
  • 4. Include a live indicator label displaying the active simulated screen class
