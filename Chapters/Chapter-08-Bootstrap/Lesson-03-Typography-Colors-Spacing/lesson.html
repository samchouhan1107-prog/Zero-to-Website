Typography, Color Palettes & Spacing Utilities

Style interfaces rapidly: margins (.m-*), paddings (.p-*), contextual colors (primary, success, dark), and text utilities.

Spacing

m-*, mt-*, mb-*, p-*, px-*, py-* (0 to 5)

Contextual Colors

primary, secondary, success, danger, dark

text-center, fw-bold, text-truncate

Borders

border, rounded-pill, shadow-sm

🎯 Learning Objectives

  • ✔ Apply the 5-step Bootstrap spacing scale (0.25rem to 3rem) systematically
  • ✔ Combine contextual color classes (.bg-success-subtle, .text-success-emphasis)
  • ✔ Format headlines and lead paragraphs using .lead and .text-muted
  • ✔ Apply subtle elevations using .shadow-sm and .shadow-lg

1. Spacing Scale and Semantic Naming

Bootstrap provides directional spacing: t (top), b (bottom), s (start/left), e (end/right), x (horizontal), and y (vertical). Scale 1=4px, 2=8px, 3=16px, 4=24px, 5=48px.

  • my-4: Vertical margin top & bottom of 24px
  • p-3: Inner padding on all sides of 16px
  • text-body-secondary: Accessible muted neutral text
