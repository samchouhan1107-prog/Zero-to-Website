Files, Folders & Project Structure

Master professional directory organization, relative vs absolute paths, naming conventions, and file management for production websites.

Root Entry

index.html

css / js / images

Relative (./ and ../)

Estimated Time

1. Professional Web Project Layout

Every maintainable website separates structural markup, styles, scripts, and media into dedicated directories:

my-web-project/
├── index.html          <!-- Main homepage / root entry point -->
├── about.html          <!-- Secondary pages in root or subdirectories -->
├── contact.html
└── assets/
    ├── css/
    │   └── style.css   <!-- Global styling rules -->
    ├── js/
    │   └── app.js     <!-- Interactive scripts -->
    └── images/
        └── logo.svg    <!-- Visual assets & photography -->

2. Relative File Paths Demystified

  • style.css: In the exact same folder as the referencing HTML file.
  • ./assets/css/style.css: Step down into the assets folder, then css.
  • ../index.html: Step UP one parent directory level.
  • ../../Assets/css/main.css: Step UP two levels to reach the root Assets folder.

3. Safe File Naming Rules

  • ✔ Always use all-lowercase letters (e.g. profile-picture.jpg).
  • ✔ Use hyphens (-) instead of spaces to avoid broken URL encoding like %20.
  • ✔ Never use special symbols like #, ?, &, or accented characters in web filenames.
