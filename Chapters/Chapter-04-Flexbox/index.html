📖 Chapter Overview

Flexbox makes arranging website layouts much easier. Instead of using floats or complicated positioning, Flexbox allows you to align, distribute and organize elements with only a few CSS properties.

Flex Container

The flex container controls layout with display: flex; and determines the main axis. It can wrap items and center them with justify-content and align-items.

Margin Labels

Margins add spacing around flex items. Common margin labels include:

  • margin-left – pushes an item from the left edge.
  • margin-right – pushes an item from the right edge.
  • margin-top / margin-bottom – control vertical spacing in wrapped rows.

Responsive Tabs

On smaller screens, flexbox content can stack or wrap. Use flex-wrap: wrap; and percentage widths to make items adapt.
