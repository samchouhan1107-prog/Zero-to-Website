Viewport Meta Tag & Media Query Breakpoints

Configure device pixel scaling, standard screen breakpoints, and modern range query syntax.

Viewport Tag

width=device-width, initial-scale=1.0

Breakpoints

640px, 768px, 1024px, 1280px

Syntax

@media (min-width: ...) & Range queries

Orientation

(orientation: landscape)

🎯 Learning Objectives

  • ✔ Recognize the catastrophic consequence of omitting the viewport meta tag
  • ✔ Establish standard responsive breakpoints (sm: 640px, md: 768px, lg: 1024px, xl: 1280px)
  • ✔ Use modern CSS Media Queries Level 4 syntax like @media (width >= 768px)
  • ✔ Test device simulations using browser developer tools

1. The Viewport Meta Tag

Without , mobile browsers assume a desktop 980px canvas and zoom out until text is unreadably microscopic. The viewport tag binds the layout viewport directly to the actual device screen width.

  • width=device-width: Sets page width to follow screen-width in device-independent pixels
  • initial-scale=1.0: Sets initial zoom level when first loaded by the browser
