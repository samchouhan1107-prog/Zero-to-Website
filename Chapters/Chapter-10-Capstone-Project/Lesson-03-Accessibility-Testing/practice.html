Practice Challenge 10.03

Accessibility Testing & WCAG Compliance

Conduct comprehensive accessibility audits and ensure your portfolio meets WCAG 2.1 AA standards

🎯 Challenge Tasks (Level: Advanced)

  • 1. Run automated accessibility testing with axe DevTools
  • 2. Conduct manual keyboard navigation testing
  • 3. Test with screen readers and identify issues
  • 4. Fix common accessibility problems found
  • 5. Implement continuous accessibility monitoring

📁 Testing Tools Setup

Required Tools:

  • axe DevTools: Chrome extension for automated testing
  • Lighthouse: Built-in Chrome accessibility scoring
  • WAVE: Web Accessibility Evaluation Tool
  • NVDA: Free screen reader for testing
  • Keyboard Navigation: Manual testing with Tab/Shift+Tab

🎯 Testing Checklist

Automated Testing Items:

  • [ ] Run axe DevTools scan on all pages
  • [ ] Check for critical and serious violations
  • [ ] Verify color contrast ratios (minimum 4.5:1)
  • [ ] Test form labels and ARIA attributes
  • [ ] Check heading structure and hierarchy
  • [ ] Verify image alt text completeness
  • [ ] Test focus indicators and keyboard traps

Manual Testing Items:

  • [ ] Navigate entire site with keyboard only
  • [ ] Test with screen reader (NVDA/VoiceOver)
  • [ ] Check color contrast with accessibility tools
  • [ ] Verify form validation feedback
  • [ ] Test responsive design on mobile devices
  • [ ] Check focus order is logical
  • [ ] Test with reduced motion preferences

🔧 Common Accessibility Issues to Fix

Priority Issues (Critical):

  • Missing Alt Text: Add descriptive alt attributes to all meaningful images
  • Missing Form Labels: Ensure all form inputs have proper labels
  • Keyboard Traps: Fix elements that trap keyboard focus
  • Missing ARIA Labels: Add ARIA labels for complex interactive elements

High Priority Issues (Serious):

  • Low Color Contrast: Ensure text meets 4.5:1 contrast ratio
  • Poor Focus Management: Ensure logical tab order and visible focus indicators
  • Missing Headings: Create proper heading hierarchy
  • Language Attribute: Add lang attribute to HTML element

Medium Priority Issues (Moderate):

  • Missing Skip Links: Add skip navigation links
  • Time Limits: Remove or adjust time limits for forms
  • Seizure Risks: Remove flashing animations or provide controls

📊 Testing Implementation

Automated Testing Script:

// accessibility-test.js
const { AxePuppeteer } = require('@axe-core/puppeteer');
const puppeteer = require('puppeteer');

class AccessibilityTester {
    constructor() {
        this.results = [];
        this.criticalIssues = [];
        this.seriousIssues = [];
    }

    async runFullTest(portfolioUrl) {
        const browser = await puppeteer.launch();
        const page = await browser.newPage();
        
        // Configure viewport for responsive testing
        await page.setViewport({ width: 1920, height: 1080 });
        
        try {
            await page.goto(portfolioUrl, { waitUntil: 'networkidle2' });
            
            // Run axe core analysis
            const axeResults = await AxePuppeteer(page).analyze();
            
            // Categorize issues by severity
            this.categorizeIssues(axeResults.violations);
            
            // Generate report
            this.generateReport(axeResults);
            
            return {
                totalViolations: axeResults.violations.length,
                criticalIssues: this.criticalIssues.length,
                seriousIssues: this.seriousIssues.length,
                report: this.generateReport(axeResults)
            };
            
        } catch (error) {
            console.error('Accessibility test failed:', error);
            throw error;
        } finally {
            await browser.close();
        }
    }

    categorizeIssues(violations) {
        violations.forEach(violation => {
            if (violation.impact === 'critical') {
                this.criticalIssues.push(violation);
            } else if (violation.impact === 'serious') {
                this.seriousIssues.push(violation);
            }
        });
    }

    generateReport(results) {
        return {
            timestamp: new Date().toISOString(),
            summary: {
                total: results.violations.length,
                critical: this.criticalIssues.length,
                serious: this.seriousIssues.length,
                moderate: results.violations.filter(v => v.impact === 'moderate').length,
                minor: results.violations.filter(v => v.impact === 'minor').length
            },
            violations: results.violations,
            passes: results.passes,
            incomplete: results.incomplete
        };
    }
}

// Usage
const tester = new AccessibilityTester();
tester.runFullTest('https://your-portfolio.com')
    .then(results => {
        console.log('Accessibility Test Results:', results);
        if (results.criticalIssues.length > 0) {
            console.log('CRITICAL ISSUES FOUND:');
            results.criticalIssues.forEach(issue => {
                console.log(`- ${issue.description}: ${issue.help}`);
            });
        }
    })
    .catch(error => {
        console.error('Test failed:', error);
    });

Manual Testing Guide:

// Manual accessibility testing checklist
class ManualAccessibilityTest {
    constructor() {
        this.issues = [];
        this.checks = [
            'keyboardNavigation',
            'screenReader',
            'colorContrast',
            'formLabels',
            'headingStructure'
        ];
    }

    async runManualTests(portfolioUrl) {
        const browser = await puppeteer.launch();
        const page = await browser.newPage();
        
        for (const check of this.checks) {
            await this[check](page);
        }
        
        await browser.close();
        return this.issues;
    }

    async keyboardNavigation(page) {
        // Test forward tab navigation
        await page.keyboard.press('Tab');
        
        // Check if focus is visible
        const focusedElement = await page.evaluate(() => {
            return document.activeElement;
        });
        
        // Check if element has visible focus indicator
        const hasFocusIndicator = await page.evaluate(() => {
            const activeElement = document.activeElement;
            const style = window.getComputedStyle(activeElement);
            return style.outline !== 'none' || 
                   style.boxShadow !== 'none' || 
                   style.border.includes('solid');
        });
        
        if (!hasFocusIndicator) {
            this.issues.push({
                type: 'keyboard',
                severity: 'serious',
                message: 'Element lacks visible focus indicator'
            });
        }
    }

    async screenReader(page) {
        // This would require more complex setup with actual screen reader
        // For now, check basic ARIA attributes
        const ariaIssues = await page.evaluate(() => {
            const issues = [];
            const elements = document.querySelectorAll('[aria-required], [aria-label]');
            
            elements.forEach(element => {
                if (element.getAttribute('aria-required') && !element.id) {
                    issues.push('Element with aria-required missing id for label reference');
                }
            });
            
            return issues;
        });
        
        ariaIssues.forEach(issue => {
            this.issues.push({
                type: 'screenreader',
                severity: 'moderate',
                message: issue
            });
        });
    }

    async colorContrast(page) {
        // Simplified color contrast check

                const style = window.getComputedStyle(element);
                // Simplified check - real implementation would calculate actual contrast
                if (style.color === 'rgb(255, 255, 255)' && style.backgroundColor === 'rgb(255, 255, 255)') {
                    issues.push('Text color matches background color');
                }

// accessibility-fixes.js
class AccessibilityFixer {
    constructor() {
        this.fixes = {
            images: this.fixImages.bind(this),
            forms: this.fixForms.bind(this),
            headings: this.fixHeadings.bind(this),
            contrast: this.fixContrast.bind(this),
            keyboard: this.fixKeyboard.bind(this)
        };
    }

    applyAllFixes() {
        Object.values(this.fixes).forEach(fix => fix());
    }

    fixImages() {
        const images = document.querySelectorAll('img:not([alt])');
        images.forEach(img => {
            if (img.getAttribute('alt') === '') {
                img.setAttribute('alt', 'Decorative image');
            } else if (!img.getAttribute('alt')) {
                // Try to derive alt text from surrounding context
                const altText = this.deriveImageAlt(img);
                img.setAttribute('alt', altText);
            }
        });
    }

    deriveImageAlt(img) {
        // Simple logic to derive alt text from context
        const parent = img.parentElement;
        const heading = parent.querySelector('h1, h2, h3, h4, h5, h6');
        if (heading) {
            return `Image related to ${heading.textContent}`;
        }
        return 'Image';
    }

    fixForms() {
        const inputs = document.querySelectorAll('input:not([type="hidden"]):not([type="submit"]):not([type="button"])');
        inputs.forEach(input => {
            if (!input.getAttribute('aria-label') && !input.getAttribute('aria-labelledby')) {
                const label = document.querySelector(`label[for="${input.id}"]`);
                if (!label) {
                    // Create hidden label
                    const hiddenLabel = document.createElement('label');
                    hiddenLabel.textContent = input.placeholder || 'Input field';
                    hiddenLabel.style.position = 'absolute';
                    hiddenLabel.style.clip = 'rect(0, 0, 0, 0)';
                    hiddenLabel.style.clipPath = 'inset(50%)';
                    hiddenLabel.style.height = '1px';
                    hiddenLabel.style.overflow = 'hidden';
                    hiddenLabel.style.whiteSpace = 'nowrap';
                    hiddenLabel.style.width = '1px';
                    input.parentNode.insertBefore(hiddenLabel, input);
                    input.setAttribute('aria-labelledby', hiddenLabel.id);
                }
            }
        });
    }

    fixHeadings() {
        // Ensure proper heading hierarchy
        const headings = document.querySelectorAll('h1, h2, h3, h4, h5, h6');
        let lastLevel = 0;
        
        headings.forEach((heading, index) => {
            const currentLevel = parseInt(heading.tagName.charAt(1));
            
            if (currentLevel > lastLevel + 1) {
                // Skip level detected
                console.warn(`Heading skip detected: ${heading.tagName} follows h${lastLevel}`);
            }
            
            lastLevel = currentLevel;
        });
    }

    fixContrast() {
        const textElements = document.querySelectorAll('p, h1, h2, h3, h4, h5, h6, span, div');
        textElements.forEach(element => {
            const style = window.getComputedStyle(element);
            const color = this.rgbToHex(style.color);
            const bgColor = this.rgbToHex(style.backgroundColor);
            
            const contrast = this.calculateContrast(color, bgColor);
            if (contrast < 4.5) {

            }
        });
    }

    rgbToHex(rgb) {
        const result = rgb.match(/\d+/g);
        if (!result) return '#000000';
        return '#' + result.map(x => parseInt(x).toString(16).padStart(2, '0')).join('');

📈 Success Criteria

Accessibility Compliance Requirements:

  • WCAG 2.1 AA Compliance: Zero critical violations, minimal serious issues
  • Keyboard Accessibility: Full keyboard navigation without traps
  • Screen Reader Compatible: Content makes sense when read aloud
  • Color Contrast: All text meets 4.5:1 contrast ratio
  • Form Accessibility: All forms properly labeled and validated
  • Responsive Design: Works across all device sizes
