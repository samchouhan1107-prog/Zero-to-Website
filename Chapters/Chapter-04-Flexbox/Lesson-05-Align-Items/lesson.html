Lesson 05 — Align Items

Learn how align-items aligns flex items along the cross axis and changes vertical placement within a row or column.

Lesson Overview

This lesson explains cross-axis alignment values like stretch, center, baseline, flex-start, and flex-end.

Introduction

align-items determines how flex items are aligned along the cross axis. It is key for vertical alignment when your main axis is horizontal.

Learning Objectives

  • Understand cross-axis alignment in Flexbox.
  • Learn the behavior of stretch, center, and baseline.
  • Use flex-start and flex-end to control item placement.

Theory

The cross axis is perpendicular to the main axis. When the flex direction is row, the cross axis is vertical. This property controls how items are placed within the height of the flex container.

Real World Example

Use align-items in card rows, button groups, and feature lists to ensure items are visually balanced and aligned.

Visual Explanation

Imagine a row of cards with different heights. stretch makes them all match the container height while center aligns them in the middle.

Code Example

.flex-container {
    display: flex;
    align-items: center;
}

Code Breakdown

align-items: center; centers items on the cross axis. stretch will grow items to fill the container height, and baseline aligns text baselines.

Related Topics

Mini Project

Summary

align-items controls how flex items align along the cross axis. It is essential for vertical control inside a horizontal layout.
