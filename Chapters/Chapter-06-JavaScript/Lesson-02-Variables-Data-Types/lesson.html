Variables, Scope & Data Types

Master modern JavaScript memory storage using const and let, and explore primitive types (string, number, boolean) and reference types.

Golden Rule

Default to const, let when mutating

Avoid

var (function scoped)

Primitives

String, Number, Boolean

Estimated Time

30 Minutes

1. const vs. let

  • const: Block-scoped, immutable binding. Use this for values, DOM elements, and arrays/objects that you don't reassign.
  • let: Block-scoped, reassignable. Use this for counters, loops, and state variables that change over time.
  • var: Legacy function-scoped declaration with hoisting pitfalls. Strictly avoid in modern projects.
