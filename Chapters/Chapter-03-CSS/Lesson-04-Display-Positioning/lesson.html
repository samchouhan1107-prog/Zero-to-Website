1. Display Property Explained

  • block: Starts on a new line and spans full width (e.g. <div>, <p>). Accepts custom width, height, margins, and padding.
  • inline: Flows within text (e.g. <span>, <a>). Ignores top/bottom margins and height.
  • inline-block: Flows inline like text, but accepts width, height, and vertical padding. Perfect for buttons and badges.
  • none: Removes the element completely from document flow.

2. The 5 CSS Position Modes

/* 1. Static (Default document flow) */
position: static;

/* 2. Relative (Offset relative to normal position, establishes anchor) */
position: relative;
top: 10px;

/* 3. Absolute (Removed from flow, positioned relative to nearest positioned ancestor) */
position: absolute;
top: 0;
right: 0;

/* 4. Fixed (Positioned relative to the browser viewport, stays on scroll) */
position: fixed;
bottom: 20px;
right: 20px;

/* 5. Sticky (Hybrid: scrolls until a threshold, then sticks to screen) */
position: sticky;
top: 0;

3. Code Example: Badge Overlay Pattern

.card {
    position: relative; /* Anchor for absolute child */
    padding: 24px;
    background: #ffffff;
}

.card .badge {
    position: absolute;
    top: -10px;
    right: -10px;
    background: #ef233c;
    color: white;
    padding: 4px 8px;
    border-radius: 9999px;
}
