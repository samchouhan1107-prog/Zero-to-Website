Practice Challenge 1.1

Build Your First Interactive Card

Modify the starter HTML code to add your custom heading, personal bio, and an interactive call to action.

🎯 Challenge Tasks

  • 1. Change the <h1> tag to say "Welcome to My Profile".
  • 2. Add a <p> tag describing what you hope to build as a web developer.
  • 3. Add a <button>Explore Projects</button>.

💡 Pro Tip

Remember to keep all visible content inside the <body> tag for the best results!

💡 Tips & Hints

  • HTML Structure: Make sure your tags are properly nested and closed.
  • CSS Styling: Use inline styles for quick experimentation.
  • Button Functionality: Buttons don't need JavaScript to be clickable - they're interactive by default!
  • Text Content: Make your bio personal and specific to your goals.

    • 🌟 Did You Know?

    The <button> element is one of the most interactive elements in HTML. It can be styled with CSS and enhanced with JavaScript for complex functionality.

    🔑 Solution

    Here's a completed version of the challenge. Compare it with your solution to see what you could improve:

    <div style="padding: 24px; border: 2px solid #ef233c; border-radius: 12px; background: #fff1f2; color: #1c0b0f; font-family: sans-serif; text-align: center;">
  <h1>Welcome to My Profile</h1>
  <p>I am learning full-stack web development with WEBZONEBW! My goal is to build modern, responsive websites that help people achieve their dreams.</p>
  <button style="background: #ef233c; color: white; border: none; padding: 10px 20px; border-radius: 6px; font-weight: bold; cursor: pointer;">Explore Projects 🚀</button>
</div>

    🎯 What Makes This Solution Great

    • Interactive Element: Button with engaging emoji
    • Visual Appeal: CSS styling makes it look professional
