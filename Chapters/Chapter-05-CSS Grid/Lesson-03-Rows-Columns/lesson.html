Rows, Columns & The Fractional Unit (fr)

Master track sizing with grid-template-columns, grid-template-rows, the powerful fr unit, and the repeat() helper function.

The Star Unit

1fr (Fraction of free space)

Helper Function

repeat(count, track-size)

Mixing Units

250px 1fr 2fr

Estimated Time

30 Minutes

1. The Fractional (fr) Unit

The fr unit represents a fraction of the available free space in the grid container after fixed tracks (pixels, rems) have been allocated.

/* 3-column layout: sidebar is 260px, main takes remaining space, extra sidebar takes 200px */
grid-template-columns: 260px 1fr 200px;

/* 3 equal columns using repeat */
grid-template-columns: repeat(3, 1fr);

/* Asymmetric 1:2 ratio */
grid-template-columns: 1fr 2fr;
