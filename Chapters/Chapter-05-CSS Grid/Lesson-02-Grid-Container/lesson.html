The Grid Container & Gap Spacing

Activate the 2D matrix engine with display: grid and learn how gap, row-gap, and column-gap separate grid tracks without margin collapses.

Activation

display: grid

Spacing

gap: row col

Inline Grid

display: inline-grid

Estimated Time

25 Minutes

1. Activating CSS Grid

Declaring display: grid on an element transforms all of its direct children into grid items aligned along horizontal rows and vertical columns simultaneously.

.grid-container {
    display: grid;
    gap: 16px; /* Uniform 16px gap between all rows and columns */
    row-gap: 24px; /* Optional custom row separation */
    column-gap: 16px; /* Optional custom column separation */
}
