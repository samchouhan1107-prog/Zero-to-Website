Lesson 06 — Flex Wrap

Understand flex-wrap and how it allows flex items to move to the next line when space is limited.

Lesson Overview

This lesson covers flex wrapping behaviors: nowrap, wrap, and wrap-reverse.

Introduction

flex-wrap controls whether flex items stay on a single line or wrap to new lines when needed. This allows responsive layouts to adapt without overflowing.

Learning Objectives

  • Learn the difference between nowrap, wrap, and wrap-reverse.
  • Understand how wrapping affects responsive layout behavior.
  • Build a row of items that wraps cleanly on smaller screens.

Theory

By default, flex containers do not wrap and items may shrink to fit. With flex-wrap: wrap;, items move to the next line when there isn't enough space, preserving layout structure.

Real World Example

Responsive cards, button groups, and feature lists often use wrapping so items remain readable on narrower screens.

Visual Explanation

nowrap keeps all items on one line. wrap creates new rows as needed. wrap-reverse wraps items upward, reversing the row order.

Code Example

.flex-container {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}

Code Breakdown

flex-wrap: wrap; allows flex items to flow into multiple lines, which improves layout behavior on smaller screens.
