# Lesson Standards

Every lesson inside WZ Storehouse must follow the same structure.

---

## Lesson Template

1. Introduction

2. Learning Objectives

3. Theory

4. Real World Example

5. Visual Explanation

6. Code Example

7. Code Breakdown

8. Related Topics

9. Practice Challenge

10. Mini Project

11. Summary

12. Previous Lesson

13. Next Lesson

---

## Lesson Rules

Every lesson should answer:

- What?
- Why?
- When?
- Where?
- How?

---

## Code Rules

Every code example should include:

Purpose

Explanation

Output

Notes

---

## Practice Rules

Every lesson must contain at least:

- One Exercise
- One Challenge
- One Solution

---

## Related Topics

Never explain future topics.

Only reference where they appear later.
