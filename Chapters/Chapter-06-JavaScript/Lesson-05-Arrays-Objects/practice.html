Practice Challenge 06.05

Inventory & Price Filter System

Build a product inventory search using JavaScript array filter() and map() that updates dynamically.

🎯 Challenge Tasks (Level: Age 15+ to Professional)

  • 1. Create an array of at least 4 product objects with id, name, category, and price
  • 2. Use .filter() to find items matching category or price under $50
  • 3. Use .map() to construct formatted HTML list items
  • 4. Render the total count of matched products in the summary bar
