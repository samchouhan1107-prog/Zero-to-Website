The capstone project brings together everything you've learned throughout the WebZoneBW SC curriculum. You'll build a professional portfolio that demonstrates your skills in modern web development, including responsive design, accessibility, performance optimization, and deployment strategies.

  • Git workflow and version control
  • CI/CD pipeline and deployment
  • Professional presentation and documentation
