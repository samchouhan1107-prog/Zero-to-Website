Chapter 04

Lesson 01 — Introduction to Flexbox

Part of the Chapter 04 Flexbox theme. This lesson introduces the core ideas behind Flexbox and how it fits into modern page layouts.

Lesson Overview

This lesson continues the chapter theme by explaining what Flexbox is, why it was introduced, and how it solves common layout problems.

Introduction

Flexbox is a powerful CSS layout system that makes arranging elements along a single axis easier. It is designed for one-dimensional layout and helps manage spacing, alignment, and order within a container.

Learning Objectives

  • Learn what Flexbox is and why it was created.
  • Understand the problems Flexbox solves compared to older CSS layout methods.
  • Identify common uses of Flexbox in modern web design.

Theory

Flexbox works by turning a container into a flexible box and its children into flex items. The container defines a main axis and cross axis, allowing items to align, grow, shrink, and wrap in a structured way.

Real World Example

Navigation menus, card rows, toolbar buttons, and module grids all benefit from Flexbox because it provides consistent spacing and alignment without extra markup or float hacks.

Visual Explanation

Imagine a row of boxes inside a container. Flexbox lets the container decide how much space each box gets, where boxes sit along the axis, and whether they should wrap onto a new line.

Code Example

<div class="flex-container">
    <div class="box">Item 1</div>
    <div class="box">Item 2</div>
    <div class="box">Item 3</div>
</div>

.flex-container {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

Code Breakdown

display: flex; turns the container into a flex container. justify-content controls alignment along the main axis, and align-items controls alignment along the cross axis.

Related Topics

Summary

Flexbox is a CSS layout system for one-dimensional layouts. It makes spacing, alignment, and responsive ordering much simpler than older CSS layout methods.
