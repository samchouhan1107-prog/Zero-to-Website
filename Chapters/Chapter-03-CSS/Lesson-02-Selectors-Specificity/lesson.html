Selectors, Specificity & The Cascade

Understand how the browser resolves conflicting style rules using the specificity score: IDs, Classes, and Type Selectors.

Hierarchy

Inline > ID > Class > Tag

Weight

(0, 1, 0) vs (0, 0, 1)

Escape Hatch

Avoid !important

Estimated Time

25 Minutes

1. The Specificity Point System

  • Inline Styles (1, 0, 0, 0): Directly on the HTML element via style="". Highest non-important precedence.
  • IDs (0, 1, 0, 0): Example: #header. Beats classes and tags.
  • Classes & Attributes (0, 0, 1, 0): Example: .btn, [type="text"], :hover. The workhorse of maintainable CSS.
  • Element Tags (0, 0, 0, 1): Example: div, p, h1. Low priority baseline defaults.
