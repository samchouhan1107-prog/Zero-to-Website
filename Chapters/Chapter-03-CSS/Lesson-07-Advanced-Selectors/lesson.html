Chapter 03 • Lesson 07

Advanced Selectors & Combinators

Master pseudo-classes (:nth-child, :is, :where, :has), attribute selectors, child combinators (>), and adjacent sibling selectors (+ and ~).

The Game Changer

:has() parent selector

Combinators

>, +, ~

Pseudo Classes

:nth-child(), :not(), :is()

Estimated Time

30 Minutes

1. Combinators Breakdown

  • parent > child: Direct Child Combinator — Selects only immediate children, ignoring nested descendants.
  • elem + sibling: Adjacent Sibling Combinator — Selects the element immediately following another element.
  • elem ~ sibling: General Sibling Combinator — Selects all following siblings at the same DOM level.

2. Modern Pseudo-Classes

/* 1. Target every second row in a table or list */
li:nth-child(even) { background: #f8fafc; }

/* 2. Group complex selectors with zero specificity penalty */
:where(header, main, footer) a { color: #ef233c; }

/* 3. The parent selector :has() */
.card:has(img) { padding-top: 0; } /* Styles the card IF it contains an image! */

/* 4. Attribute selection */
a[href^="https://"]::after { content: " ↗"; } /* External link indicator */
