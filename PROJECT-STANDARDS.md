# WZ Storehouse - Project Standards

This document defines the development standards, lesson structure, coding guidelines, and design principles for the WZ Storehouse platform. Every chapter, lesson, feature, and project must follow these standards to ensure a consistent learning experience and maintainable codebase.

---

# Project Information

**Project Name:** WZ Storehouse

**Version:** 1.0 Alpha

**Status:** In Development

**Developer:** Sameer Chouhan

**Platform Type:** Developer Learning Platform

---

# 1. Project Philosophy

WZ Storehouse is designed to help learners become confident developers through structured lessons, visual learning, practical coding exercises, and real-world projects.

### Core Learning Principles

- Read
- Understand
- Visualize
- Practice
- Build
- Repeat

Every lesson should encourage learners to think, experiment, and solve problems independently.

---

# 2. Lesson Structure

Every lesson throughout the platform must follow the same structure.

1. Introduction
2. Learning Objectives
3. Theory & Explanation
4. Real-World Example
5. Visual Explanation
6. Code Example
7. Code Breakdown
8. Related Topics
9. Practice Challenge
10. Summary
11. Previous Lesson
12. Next Lesson

Consistency is one of the most important goals of WZ Storehouse.

# 4. User Interface Standards

Every page should maintain the same layout for a consistent learning experience.

### Required Components

- Header
- Sidebar Navigation
- Main Content Area
- Footer
- Settings Panel
- Previous / Next Navigation

Future features may include:

- Dark Mode
- Search Lessons
- Reading Mode
- Font Size Controls
- Language Selection

---

# 5. Development Standards

Before adding a new feature, always ask:

> **Does this improve the learner's experience?**

If the answer is **No**, the feature should not be added.

Keep the platform:

- Simple
- Clean
- Beginner Friendly
- Easy to Navigate
- Easy to Maintain

---

# 6. File Organization Standards

Project files should remain organized and reusable.

### HTML

Use HTML only for:

- Structure
- Content
- Navigation
- Images
- Forms

### CSS

Use CSS only for:

- Layout
- Colors
- Typography
- Components
- Animations
- Responsive Design

### JavaScript

Use JavaScript only for:

- Interactive Features
- Navigation Logic
- Settings
- Search
- Theme Controls
- Dynamic Behaviour

---

# 7. Project Goal

The long-term objective of WZ Storehouse is to become a complete developer learning platform that combines:

- Structured Lessons
- Practical Coding Exercises
- Interactive Learning
- Real-World Projects
- Portfolio Development
- Career Preparation
