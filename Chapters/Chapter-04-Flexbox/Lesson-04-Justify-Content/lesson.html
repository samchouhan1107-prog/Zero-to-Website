Lesson 04 — Justify Content

Learn how justify-content aligns flex items along the main axis and controls spacing between them.

Lesson Overview

This lesson explains the main-axis alignment values for Flexbox, including start, center, end, space-between, space-around, and space-evenly.

Introduction

justify-content moves flex items along the main axis. It is one of the most common properties for distributing space inside a flex container.

Learning Objectives

  • Understand how justify-content affects item placement.
  • Learn the difference between start, center, and end.
  • Use spacing values like space-between, space-around, and space-evenly.

Theory

When items are placed along the main axis, justify-content determines the starting point and spacing strategy. Different values position items at the start, center, end, or distribute the extra space evenly.

Real World Example

Use justify-content in header toolbars, button groups, and card layouts so items are spaced clearly across the row.

Visual Explanation

start packs items at the beginning, center balances them, end pushes them to the end, and the space values distribute remaining room.

Code Example

.flex-container {
    display: flex;
    justify-content: space-between;
}

Code Breakdown

space-between places the first item at the start and the last item at the end, spreading the remaining items evenly between them.

Related Topics

After this lesson, the next step is aligning items on the cross axis with align-items in Lesson 05.

Practice Challenge

Create a navigation bar where the logo stays at the left and menu items stretch evenly across the row.

Mini Project

Build a toolbar layout with three buttons: one at the start, one centered, and one at the end.

Summary

justify-content is the key Flexbox property for spacing flex items along the main axis. Choose the alignment value based on how you want items distributed.
