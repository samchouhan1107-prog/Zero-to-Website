Practice Challenge 07.03

Zero-Media-Query Fluid Hero Section

Build a responsive hero banner that adapts font size, padding, and button width using only clamp() and min().

🎯 Challenge Tasks (Level: Age 15+ to Professional)

  • 1. Apply clamp() to the main heading font size (min: 24px, max: 48px)
  • 2. Apply clamp() to section outer padding (min: 16px, max: 48px)
  • 3. Set button width to min(100%, 280px) so it's full-width on mobile and comfortably fixed on desktop
  • 4. Verify fluid behavior without any @media rules
