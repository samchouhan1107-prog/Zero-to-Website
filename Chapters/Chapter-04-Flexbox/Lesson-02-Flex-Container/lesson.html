Chapter 04

Lesson 02 — Flex Container

Learn how a flex container defines layout direction, axes, and wrapping behavior for its child items.

Lesson Overview

This lesson explains display: flex;, the flex container, the main axis, the cross axis, and the core flex item sizing rules.

Introduction

The flex container is the parent element that enables Flexbox layout. Once it is set with display: flex;, its children become flex items that respond to the flex layout rules.

Learning Objectives

  • Understand display: flex; and how to create a flex container.
  • Learn the difference between the main axis and cross axis.
  • Explore flex item properties: order, flex-grow, flex-shrink, and flex-basis.

Theory

When an element becomes a flex container, the default main axis runs left-to-right and the cross axis runs top-to-bottom. Flex items can change their order, grow to fill space, shrink to fit, and use a base size.

  • order: changes the visual order of flex items without changing HTML.
  • flex-grow: allows an item to expand and take available space.
  • flex-shrink: lets an item shrink when space is limited.
  • flex-basis: sets the starting size of a flex item before growing or shrinking.

Real World Example

Flex containers are often used for navigation bars, card rows, and feature sections. Each item can adapt to the available width while maintaining alignment and spacing.

Visual Explanation

The main axis runs in the direction of the chosen layout (usually row). The cross axis is perpendicular. justify-content aligns items along the main axis, while align-items aligns along the cross axis.

Code Example

<div class="flex-container">
    <div class="item">One</div>
    <div class="item">Two</div>
    <div class="item">Three</div>
</div>

.flex-container {
    display: flex;
    justify-content: space-between;
    align-items: center;
    flex-wrap: wrap;
}

.item {
    flex: 1 1 180px;
}

Code Breakdown

display: flex; activates Flexbox. justify-content distributes items along the main axis. align-items sets cross-axis alignment. flex: 1 1 180px; combines grow, shrink, and basis.

Related Topics

These concepts matter before you use justify-content, align-items, and flex-wrap in later lessons.

Practice Challenge

Mini Project

Summary

The flex container starts the Flexbox layout. The main axis and cross axis define alignment directions, and flex item properties control order, growth, shrinkage, and base size.
